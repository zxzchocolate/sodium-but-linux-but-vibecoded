# Upstream provenance and license notes

The original `dev` branch was based on the public [CaffeineMC/Sodium](https://github.com/CaffeineMC/sodium) repository. The original repository's primary license file is PolyForm Shield 1.0.0; see [LICENSE.md](LICENSE.md). Its original source tree also contains separate third-party components and notices.

This clean prototype branch does not currently include Sodium renderer source files or the Minecraft/Fabric/NeoForge implementation. The demo under `renderer-prototype/` is a small independent SDL2/OpenGL proof of concept.

Before reusing code from the upstream Sodium tree, review the exact file's license and provenance, preserve all required notices, and obtain qualified legal advice about the PolyForm Shield noncompete clause. Do not assume the upstream license is equivalent to MIT, Apache-2.0, or GPL.
